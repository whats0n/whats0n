## `Changelog`

### `[6.0.0]` — Kombine · Frontend Team Lead <sub>`latest`</sub>

<sup>April 2024 → present</sup>

**Added**

- Frontend architecture, coding standards and the shared component library of a 3-brand iGaming platform — **400k+ registered / 200k+ confirmed players**.
- A frontend team of 4–6 engineers: planning, code review, one-on-ones, mentoring.
- Competitor teardowns turned into feature proposals that actually made it to the roadmap.

**Performance**

- **Halved** game page load time by redesigning the page's data-loading pipeline.
- Lifted Lighthouse performance out of the red band (`<50`) into `50+` across key pages.
- Cut build time by **20–25%**, shortening the feedback loop for the whole team.

**Fixed**

- SSR hydration mismatches that only reproduced on specific clients — built a custom logger once Sentry quotas ran short, then safely patched DOM APIs to isolate the root cause in production.

<br>

### `[5.0.0]` — Perfection.dev · Senior Frontend Developer

<sup>December 2022 → April 2024</sup>

**Added**

- Admin panel, demo sites and the main client application on Vue / Nuxt + TypeScript, all sharing one design system.
- An internal CLI tool built with `oclif`, automating project setup and release workflows.
- A real-time content and layout designer — complex DOM mutations, non-trivial data structures.

**Changed**

- UI consistency and delivery speed across the whole product suite.

<br>

### `[4.0.0]` — Wild Tornado · Head of IT / Team Lead

<sup>October 2021 → July 2022</sup>

**Added**

- A cross-functional team — developers, QA and DevOps — under one process.
- Reusable modules and shared infrastructure that shortened the launch time of new projects.
- Quality gates: code review, release checklists, testing standards, internal training.

**Removed**

- The company shut down its entire IT department. Org-wide, not team-scoped.
